# Web UI 已登录－未订阅测试用例

环境：连接的 iPhone 普通 Chrome；游客状态由网页登录状态区分。仅验证订阅入口，不购买。举报和拉黑最后执行。

来电与轮播按账号、数据条件分支执行；未满足条件不计为通过。新旧账号必须有界面或其他可靠依据。

## 登录

### L-01 登录弹窗的两个协议正文非空

- 测试步骤
  - 1、在普通 Chrome 中以网页游客身份打开 Profile，确认登录弹窗出现
  - 2、分别点击 Terms of Service、Privacy Policy，读取正文后返回
- 预期结果
  - 1、两个协议均可打开，有标题和非空正文，可返回登录入口

### L-02 Google 登录并确认实际会员状态

- 测试步骤
  - 1、从 Profile 登录弹窗点击 Continue with Google
  - 2、优先选择已有指定 Google 账号；需要凭据时由交互输入，不保存凭据
  - 3、完成回调后立即观察Chat新老用户窗口，并刷新Profile核对账号及实际会员卡片
- 预期结果
  - 1、返回被测站点，Profile 显示已登录身份；Premium Member与Active until有效期表示已订阅，Upgrade to Premium表示未订阅，无法确认则阻塞关联项

## Discover

### L-03 已登录 Discover 存在用户卡片

- 测试步骤
  - 1、确认已登录未订阅，打开 Discover
  - 2、检查卡片内容及用户操作入口
- 预期结果
  - 1、至少一张用户卡片可见，图片、用户信息和操作入口可识别

### L-07 Say Hi 成功下落通知

- 测试步骤
  - 1、选择尚未打招呼且可用额度大于零的用户，记录目标
  - 2、点击 Say Hi，立即采集通知和按钮状态
- 预期结果
  - 1、出现明确的 Say Hi 成功下落通知

### L-08 给五个不同用户打招呼后第六次触发订阅

- 测试步骤
  - 1、确认本轮账号打招呼初始用量为零；未知或历史消耗时记录前置条件不足
  - 2、依次向五个不同用户发送 Say Hi，记录目标及每次结果
  - 3、向第六个未打招呼用户点击 Say Hi
- 预期结果
  - 1、前五次成功，第六次出现订阅弹窗；只有历史额度不足不能判定五次边界通过

### L-09 卡片 Video 触发订阅

- 测试步骤
  - 1、已登录未订阅时，在 Discover 点击用户卡片的 Video
- 预期结果
  - 1、出现订阅弹窗

### L-11 卡片打码标签触发订阅

- 测试步骤
  - 1、在 Discover 寻找具有打码标签的用户卡片
  - 2、点击该打码标签
- 预期结果
  - 1、出现订阅弹窗；不存在该标签时记录测试数据不足

## 来电

### L-04 新注册三分钟内收到来电并取消

- 测试步骤
  - 1、真实登录成功后立即进入Chat，30秒内出现teamoffice消息则认定新用户，无消息则为老用户；错过窗口不得追溯
  - 2、新用户在登录后三分钟窗口内观察来电，首次点击取消
- 预期结果
  - 1、新用户三分钟内出现模拟视频来电，点击取消后消息关闭且页面可操作；老用户跳过本项

### L-05 新注册第二次来电接听

- 测试步骤
  - 1、沿用本次登录后30秒Chat的teamoffice新用户判定，不重复登录或重新计时
  - 2、完成首次来电取消后，再次来电时点击接听
- 预期结果
  - 1、第二次消息出现，接听后进入对应通话界面；老用户跳过；未收到第二次来电则记录等待范围与阻塞

### L-06 非新注册用户无欢迎来电

- 测试步骤
  - 1、登录后完整观察Chat三十秒无teamoffice消息，按老用户处理
  - 2、登录后在前台连续观察三分钟，记录观察起止
- 预期结果
  - 1、观察窗口内不出现新注册欢迎视频来电；不据此推断无限时段行为

## 轮播与返回

### L-20 多图自动轮播

- 测试步骤
  - 1、进入具有至少两张资料图片的详情，记录实际图片数量
  - 2、不手动滑动，连续观察至少两次图片自动切换，记录实测间隔
- 预期结果
  - 1、多张图片能够自动轮播，3秒间隔可接受，不要求固定4秒；无多图数据时阻塞

### L-21 单图不轮播

- 测试步骤
  - 1、进入仅一张资料图片的详情，确认图片数量
  - 2、前台观察至少八秒，记录图片及指示器
- 预期结果
  - 1、图片保持该用户唯一资料图片，不出现空白或轮播跳动；无单图数据时阻塞

### L-22 详情返回来源页面

- 测试步骤
  - 1、从 Discover 记录目标卡片并进入详情
  - 2、点击详情返回
- 预期结果
  - 1、返回 Discover 来源页面，可继续浏览和打开卡片
