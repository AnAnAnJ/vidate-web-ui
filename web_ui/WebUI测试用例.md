# Web UI UI 测试用例

**测试范围与统一约定**

- 环境：Chrome，优先使用已连接手机的真实设备视口；同时覆盖桌面 Chrome。
- 游客入口：打开首页，点击 `Start Video Chat for FREE`，进入 `/lobby/match`；点击 `Discover` 进入 `/lobby/anchor`。
- 游客指被测网页未登录状态，不指 Chrome 无痕模式。使用普通 Chrome 标签页，不点击 `Continue with Google`；登录弹窗只验证并关闭。
- 匹配前检查游客剩余次数；显示 `Log in to continue` 或次数为 0 时记录阻塞，不切换登录态。
- 每条匹配用例只主动启动一次匹配；完成操作后立即点击 `Exit`，不做连续匹配或压力测试。若网页自动续配，记录已消耗次数和退出时机。摄像头和麦克风使用测试设备。
- 结果记录：每条用例记录实际 URL、截图、控制台错误、网络失败请求、弹窗/Toast 文案和最终状态。

## 游客模式

### G-01 游客进入应用匹配页
- 测试步骤
  - 1、确认被测网页已退出登录，在普通 Chrome 标签页打开首页。
  - 2、点击 `Start Video Chat for FREE`。
- 预期结果
  - 1、跳转到 `/lobby/match`，页面不白屏、不出现未处理异常。
  - 2、顶部显示 `Log in`，匹配入口和 `Discover` 按钮可见。

### G-02 游客进入 Discover 页面
- 测试步骤
  - 1、在 `/lobby/match` 点击 `Discover`。
  - 2、等待列表完成加载。
- 预期结果
  - 1、跳转到 `/lobby/anchor`。
  - 2、显示 `All / Video / Text` 三个 Tab，加载态结束后出现卡片或明确空态。

### G-03 Discover 切换 All、Video、Text Tab
- 测试步骤
  - 1、记录当前 URL、Tab 选中状态和卡片数量。
  - 2、依次点击 `Video`、`Text`、`All`。
  - 3、每次切换等待接口和 loading 完成。
- 预期结果
  - 1、每次仅一个 Tab 处于选中状态，Tab 文案和选中样式正确。
  - 2、页面无白屏、JS 错误、重复卡片或布局跳动。
  - 3、筛选结果与 Tab 类型一致；无数据时显示空态而非报错。

### G-04 Discover 卡片内容完整性
- 测试步骤
  - 1、在 `All` Tab 读取首屏全部卡片。
  - 2、逐张检查头像/媒体区域、在线状态、昵称或年龄、`Say Hi`、`Video`。
- 预期结果
  - 1、每张卡片容器尺寸稳定，无重叠、裁切和横向溢出。
  - 2、卡片操作按钮可见且可点击，缺失字段按约定占位。
  - 3、同一用户不重复展示，加载失败时有可识别的占位或错误态。

### G-05 Discover 列表连续下滑 5 次
- 测试步骤
  - 1、回到 `All` Tab，记录首屏卡片 ID/昵称。
  - 2、向下滚动 5 次，每次滚动后等待列表稳定。
  - 3、记录新增卡片、滚动位置和网络请求。
- 预期结果
  - 1、滚动过程中无卡死、跳回顶部、空白大块区域或布局抖动。
  - 2、触底加载时显示 loading 或明确结束提示，不重复请求同一页。
  - 3、已有卡片不重复，滚动后仍可返回顶部并保持 Tab 状态。

### G-06 游客点击卡片 Say Hi 弹出登录弹窗
- 测试步骤
  - 1、在有卡片的 Discover 页面点击任意一张卡片的 `Say Hi`。
  - 2、记录弹窗标题、按钮和背景遮罩。
- 预期结果
  - 1、弹出登录弹窗，不发送聊天消息。
  - 2、弹窗包含 `Continue with Google`、Terms/Privacy 文案和可关闭操作。
  - 3、关闭弹窗后仍停留在 Discover，Tab、滚动位置和卡片状态不丢失。

### G-07 游客点击卡片 Video 弹出登录弹窗
- 测试步骤
  - 1、在另一张卡片点击 `Video`。
  - 2、观察弹窗、URL 和网络请求。
- 预期结果
  - 1、弹出登录弹窗，不进入通话、不扣匹配次数。
  - 2、关闭弹窗后页面状态保持不变，不能产生重复弹窗或多次请求。

### G-08 游客在 Discover 点击底部登录入口
- 测试步骤
  - 1、滚动到列表底部，点击 `Log in`。
  - 2、关闭弹窗，再重复点击一次。
- 预期结果
  - 1、首次点击弹出登录弹窗。
  - 2、重复点击只保留一个弹窗实例，关闭后页面可继续操作。

### G-09 游客 Match 页登录拦截或直接匹配分支
- 测试步骤
  - 1、进入 `/lobby/match`，记录 `Start matching` 的实际文案和可用状态。
  - 2、点击 `Start matching` 一次。
- 预期结果
  - 1、若显示 `Log in to continue`：记录游客额度或入口阻塞，不点击登录按钮，不扣次数。
  - 2、若游客开关允许匹配：进入权限流程或匹配中页面，记录实际 URL 和状态。
  - 3、完成本条检查后退出匹配，不继续下一轮。

### G-10 游客拒绝摄像头或麦克风权限
- 测试步骤
  - 1、在允许游客匹配的环境进入权限流程。
  - 2、首次点击 `Continue`，在 Chrome 权限提示中拒绝摄像头或麦克风。
- 预期结果
  - 1、页面明确提示缺少哪项权限及开启方式。
  - 2、匹配不进入成功态，不展示可用的虚假视频流。
  - 3、页面仍可点击 `Try again` 或返回，不崩溃。

### G-11 拒绝权限后点击 Try again
- 测试步骤
  - 1、完成 G-10，点击 `Try again`。
  - 2、再次观察权限提示和页面状态。
- 预期结果
  - 1、页面重新发起权限检查或刷新流程，权限拒绝提示可再次出现。
  - 2、不会重复叠加弹窗、创建多个本地媒体流或重复扣次数。

### G-12 游客允许权限后的内置通知
- 测试步骤
  - 1、在权限流程点击 `Allow`，允许摄像头和麦克风。
  - 2、等待页面完成设备初始化。
- 预期结果
  - 1、页面显示权限已开启的 Toast/下落通知或等效反馈。
  - 2、视频预览能显示真实设备流；无权限错误和黑屏异常。

## 游客 Match 与通话

### M-09 Match 顶部三个 Tab 切换
- 测试步骤
  - 1、保持网页游客状态进入 `/lobby/match`。
  - 2、依次点击顶部三个 Tab，再返回原 Tab。
- 预期结果
  - 1、每次切换 URL、标题、选中状态和内容区域正确。
  - 2、切换无白屏、重复请求、状态错乱；返回后可继续匹配。

### M-10 Match 中间 Discover 跳转
- 测试步骤
  - 1、在 Match 页点击中间 `Discover`。
- 预期结果
  - 1、跳转到 `/lobby/anchor`，Discover Tab 和列表正常加载。
  - 2、浏览器后退可回到 Match，仍保持游客状态。

### M-11 游客有剩余次数时开始匹配
- 测试步骤
  - 1、确认未登录，记录页面显示的 `X free matches left`，仅在 X 大于 0 时继续。
  - 2、点击一次 `Start matching`，完成所需权限授权。
- 预期结果
  - 1、进入匹配中页面或匹配链接页，显示取消/退出入口。
  - 2、按产品规则扣减本次匹配次数；完成检查后立即退出，不进行自动连续匹配。

### M-12 匹配中点击 Exit
- 测试步骤
  - 1、游客进入匹配链接页，记录开始前次数和匹配状态。
  - 2、点击 `Exit`，确认退出（若有确认弹窗），记录退出后次数。
- 预期结果
  - 1、匹配任务结束并返回 Match 或约定页面。
  - 2、一次匹配最多扣减一次；退出后不自动开始下一轮。

### M-13 匹配成功后发送英文问候
- 测试步骤
  - 1、游客只启动一次匹配，等待成功并进入通话聊天界面。
  - 2、输入一条简短、非固定的英文问候并点击发送，例如 `Hi there!` 或 `Hello!`。
  - 3、确认消息后立即退出，不继续匹配。
- 预期结果
  - 1、消息显示在当前通话中，发送者和内容与本次实际输入一致。
  - 2、输入框清空，不重复发送；退出后不自动开始下一轮。

### M-14 匹配成功后切换视频视角
- 测试步骤
  - 1、游客只启动一次匹配，在双视频窗口页面点击右上角自己的视角窗口。
  - 2、确认切换后立即退出，不继续匹配。
- 预期结果
  - 1、两个视频窗口主次位置切换一次。
  - 2、远端视频和自己的视频源不变，控件位置和可操作性正常。

### G-17 Profile 游客拦截
- 测试步骤
  - 1、确认被测网页为游客状态，点击底部或顶部 `Profile`。
- 预期结果
  - 1、弹出登录弹窗或跳转登录页。
  - 2、关闭后页面可继续浏览，不能进入他人账户资料。

## 游客异常与兼容性补充

### E-01 首次加载慢和接口失败
- 测试步骤
  - 1、使用 Chrome 网络限速或断网后进入 Match、Discover。
  - 2、恢复网络并点击重试（若提供）。
- 预期结果
  - 1、显示 loading、空态或错误提示，不出现白屏。
  - 2、恢复后只加载一次正确数据，失败请求可重试且不重复追加卡片。

### E-04 移动端横竖屏和窄宽度布局
- 测试步骤
  - 1、在连接手机上分别测试竖屏、横屏；桌面 Chrome 测试窄窗口。
  - 2、检查导航、Tab、卡片、视频窗口、输入框和弹窗。
- 预期结果
  - 1、无横向滚动、文字遮挡、按钮出屏、视频比例异常。
  - 2、键盘弹出后输入框和发送按钮仍可见，弹窗可关闭。

### E-05 摄像头和麦克风设备异常
- 测试步骤
  - 1、在系统中切换、占用或拔出摄像头/麦克风后进入权限流程。
  - 2、观察错误提示和重试流程。
- 预期结果
  - 1、明确提示设备不可用，并给出选择设备或重试路径。
  - 2、不会把黑屏、静音误报为权限已成功。

### E-06 隐私与条款入口可达性
- 测试步骤
  - 1、从首页和登录弹窗分别打开 `Privacy Policy`、`Terms of Service`。
  - 2、检查返回路径和游客状态。
- 预期结果
  - 1、链接地址正确、页面可加载、返回后原页面状态保持。
  - 2、登录弹窗中的协议文案与页面链接一致，不出现死链。
